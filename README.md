# STRATA project page

Static site (no build step, no dependencies) for the paper *STRATA: Sub-Task Boundary Detection for
Long-Horizon Robot Demonstrations via Telemetry-Vision Fusion* (TVF detector + FOCUS uncertainty).
Design follows the ROAM page's structure (dark hero, author band, chaptered sections, BibTeX copy)
with a crimson identity. All numbers are copied from the final PDF (Tables 1–5, 8, 13, 15).

Preview (private): https://claude.ai/artifact/Rs7NALzfhYWCof2ZLhLP6f

## Files

```
index.html                 page (GitHub Pages entry point)

static/data/episodes.js    generated by tools/build_examples.py

tools/build_examples.py    explorer data + frames for the chosen recordings
tools/build_videos.py      video cards (static/video/<ep>.mp4, 4x) + hero background (hero.mp4, 2x, rec 626)

```

## Update the figures from the PDF

```
cp <final>.pdf paper/strata.pdf
python3 tools/extract_paper_figs.py paper/strata.pdf
```

Done on 2026-11-26 from `paper/strata.pdf` (the 24-page submission); all 8 figures extracted and checked.
Crops end just above each caption (positions from `pdftotext -bbox`). The script writes
`static/img/paper/extracted.js`; figures missing from it show an "older render" badge, and missing files hide.
`paper/` is git-ignored: it holds the confidential review copy.

### Deploy to GitHub Pages as `<name>.github.io`

The repo is already initialised here (branch `main`, author "STRATA authors" set for this repo only, so
your name stays off the anonymous site). `/paper/` (review copy + pipeline source PDF) is git-ignored.

1. On github.com: **+ → New organization → Free**, name it e.g. `strata-robot` (ROAM does the same:
   org `roam-hiking` → `roam-hiking.github.io`). A personal account works too, but its username
   becomes the URL and reveals who you are during review.
2. In that organization: **New repository**, name exactly `strata-robot.github.io`, **Public**, no README.
3. Create a token: **Settings → Developer settings → Fine-grained tokens**, resource owner = the
   organization, repository = that repo, permission **Contents: Read and write**.
4. Push from this server (SSH to github.com is blocked here; HTTPS works). Paste the token when asked
   for a password:
   ```
   cd /mnt/ssd-storage/trinhpn/strata_web
   git remote add origin https://github.com/strata-robot/strata-robot.github.io.git
   git push -u origin main
   ```
5. Repo **Settings → Pages → Build and deployment**: Source = *Deploy from a branch*, branch `main`,
   folder `/ (root)`. The site is live at `https://strata-robot.github.io` a minute later.

Cache: run `python3 tools/stamp.py` before every commit that changes CSS/JS/data. It adds `?v=<hash>` to every
CSS/JS link (GitHub Pages lets browsers keep files 10 min, which once paired a new index.html with an old main.js).

Later changes: edit, `git commit -am "..."`, `git push`. Before going public, decide on the draft
banner in `index.html` and do not name the venue while the paper is under double-blind review.
